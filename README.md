# João Vitor Ferrer — Portfólio QA

Site do portfólio em **React + TypeScript + Vite**, com deploy automático no GitHub Pages.

## Live

https://jvferrer.github.io/Portifolio_JoaoVitor/

## Stack

- React 19 + TypeScript
- Vite
- Playwright (E2E)
- GitHub Actions → Pages

## Desenvolvimento

```bash
cd portfolio
npm ci
npm run dev
```

## Testes e build

```bash
cd portfolio
npm run test:e2e:chromium
npm run build
```
