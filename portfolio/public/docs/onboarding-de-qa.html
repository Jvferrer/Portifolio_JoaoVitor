2. Extensão FengXT

Na primeira semana, instale a FengXT. Ela concentra o acesso aos sistemas da Feng (Admin, FengST, MatchDay, Intranet, Notion) e as ferramentas do dia a dia (Clockify e Pomodoro).

Repositório interno da extensão. Peça acesso ao time antes de clonar.

Instalar

Pré-requisitos: Google Chrome, Node.js 20 ou superior, conta Microsoft da Feng e o Doppler CLI autenticado no projeto interno da extensão.

git clone <repositório interno da extensão>
cd <pasta da extensão>
npm install
npm run build
  1. Abra chrome://extensions
  2. Ative o Modo do desenvolvedor
  3. Clique em Carregar sem compactação
  4. Selecione a pasta dist gerada no projeto

Como usar

  1. Clique no ícone da FengXT na barra do Chrome.
  2. Escolha Entrar com Microsoft e use a conta organizacional.
  3. No menu, abra o sistema da squad (Painel Admin, FengST, MatchDay, Intranet ou Notion).
  4. Em Ferramentas, use o Clockify para registrar horas e o Pomodoro para os ciclos de foco.
  5. Opcional: em chrome://extensions/shortcuts, defina um atalho para abrir a extensão.

Se o login falhar, confirme que a conta é a Microsoft da empresa e que o acesso ao GitHub e ao Doppler já foi liberado. Recarregue a extensão em chrome://extensions se o ícone não aparecer depois do build.

Classifique o que você está validando antes de executar o CT.

Não funcionalDesempenho e cargaStress em dia de clássico

8. Checklist operacional

Antes de marcar um item como concluído no Jira, confira:

  • Cenário escrito em BDD (Dado / Quando / Então)
  • Evidência anexada (print, log ou query)
  • Status atualizado no Jira
  • CT classificado como Positivo, Negativo ou Alternativo
  • Cenários alternativos validados em execução separada
  • Validação em Frontend + Banco + API (quando aplicável à feature)
  • Ambiente informado: DEV, HOMOLOGAÇÃO ou PRODUÇÃO
